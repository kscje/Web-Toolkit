你好，请帮我用 JavaScript 写一个快速排序，并解释时间复杂度。

好的，下面是一个 JavaScript 版本的快速排序实现：

function quickSort(arr) {
  if (arr.length <= 1) return arr;
  const pivot = arr[Math.floor(arr.length / 2)];
  const left = arr.filter(x => x < pivot);
  const mid = arr.filter(x => x === pivot);
  const right = arr.filter(x => x > pivot);
  return [...quickSort(left), ...mid, ...quickSort(right)];
}

时间复杂度分析：

  • 平均情况：O(n log n)
  • 最坏情况：O(n²)（例如已排序数组）

更多细节可参考 维基百科。

能不能改成原地排序的版本？

可以，下面是 原地（in-place）版本，使用 Lomuto 分区方案：

function quickSortInPlace(arr, lo = 0, hi = arr.length - 1) {
  if (lo >= hi) return arr;
  const p = partition(arr, lo, hi);
  quickSortInPlace(arr, lo, p - 1);
  quickSortInPlace(arr, p + 1, hi);
  return arr;
}

原地排序将空间复杂度降到 O(log n)（递归栈）。
